# NEXT IT ACADEMY

다크 네이비와 블루를 사용한 IT 전문 교육기관 홍보 홈페이지입니다.
HTML, CSS, JavaScript만 사용하며 별도 설치나 빌드가 필요하지 않습니다.

## 실행 방법

1. `D:\Study_9\Exam` 폴더를 엽니다.
2. `index.html`을 더블 클릭하거나 브라우저 창으로 끌어 놓습니다.
3. 최신 Chrome, Edge, Firefox, Safari에서 확인합니다.

인터넷 연결 없이도 실행할 수 있습니다. 외부 폰트, 이미지, 라이브러리를 불러오지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 내비게이션, 메인 홍보, 교육과정, 학원 소개, 하단 영역, 상세 안내 창 |
| `style.css` | 색상, 레이아웃, 반응형 화면, Hover 및 키보드 포커스 효과 |

## 5단계 구성

1. **구조**: 한국어 콘텐츠와 의미에 맞는 HTML 영역 구성
2. **디자인**: 네이비·블루 색상, 코드 에디터 비주얼과 교육과정 카드 구현
3. **반응형**: PC·태블릿·모바일 레이아웃과 모바일 메뉴 구현
4. **기능**: 영역 이동, 과정별 상세 안내, 키보드 접근성 구현
5. **확인**: 파일 연결, 버튼 동작과 화면별 확인 항목 정리

## 사용 및 확인

- 홈·교육과정·학원 소개 메뉴와 메인 버튼은 해당 영역으로 이동합니다.
- 모바일에서는 메뉴 버튼으로 내비게이션을 열고 닫습니다. 메뉴 선택 및 Escape 키로도 닫힙니다.
- 과정별 '과정 자세히 보기'는 학습 순서가 담긴 안내 창을 엽니다.
- 안내 창은 닫기, 확인했어요, Escape 키로 닫습니다.
- Tab 키로 링크와 버튼에 접근할 수 있습니다. 안내 창에는 브라우저 기본 dialog 포커스 처리가 적용됩니다.
- 운영체제의 동작 줄이기 설정에 따라 부드러운 스크롤과 전환 효과를 줄입니다.
- 브라우저 창을 약 375px, 768px, 1440px 너비로 바꾸어 가로 넘침과 가독성을 확인하세요.

GitHub Push 및 외부 배포는 수행하지 않습니다.

## 미니 코드 에디터

메인 오른쪽 `your-next-chapter.js`는 직접 편집할 수 있는 코드 입력창입니다. 별도 라이브러리나 설치가 필요하지 않으며 코드를 실행하지 않습니다. 기존 TERMINAL은 안내용 표시입니다.

- 원하는 위치를 클릭해 입력하거나 선택, 삭제, 복사, 붙여넣기할 수 있습니다.
- Enter, Backspace, Delete는 브라우저 textarea의 기본 동작을 사용합니다.
- Tab은 선택 영역을 공백 두 칸으로 바꿉니다. Shift+Tab 또는 Escape 다음 Tab으로 입력창 밖으로 이동합니다. 한글 조합 중에는 Tab 처리를 가로채지 않습니다.
- 실제 줄 수에 맞춰 번호가 바뀌며, 긴 코드는 입력창 안에서 가로·세로 스크롤합니다.
- 주석, 문자열, 주요 키워드, 숫자, 함수 호출에 간단한 색상 강조를 적용합니다. 완전한 JavaScript 파서는 아니므로 정규 표현식 리터럴이나 템플릿 문자열 내부 표현식 등 복잡한 문법은 정확히 구분하지 못할 수 있습니다.
- 상단 X로 닫으면 자리를 유지한 채 사라지며, 같은 위치의 '코드 에디터 다시 열기'로 복원됩니다. 입력 내용과 스크롤 위치를 유지합니다.
- 하단 '초기화'에서 확인을 선택하면 처음의 12줄 예시로 복원하고 저장합니다. 취소하면 현재 코드를 유지합니다.

### 자동 저장

입력할 때마다 localStorage 키 `next-it-academy:mini-editor:code:v1`에 저장합니다. 저장된 값이 없는 경우에만 예시를 사용하므로, 전체 삭제 후 저장한 빈 내용도 그대로 복원됩니다. 저장 완료·복원·저장 불가 상태는 에디터 하단에서 확인할 수 있습니다.

동일 브라우저·프로필·페이지 주소에서 새로고침하거나 브라우저를 다시 열면 저장된 코드를 불러옵니다. 사이트 데이터 삭제, 비공개 모드 종료 또는 브라우저 저장 정책에 따라 보존되지 않을 수 있습니다. 특히 `file://` 주소의 localStorage 지원과 저장 범위는 브라우저마다 다르므로 동일 파일 경로에서 확인하세요. 저장이 제한되거나 용량을 초과하면 편집과 닫기·다시 열기는 계속 사용할 수 있지만 새로고침 후 보존은 보장하지 않습니다.

### 검증 범위와 직접 확인 방법

이번 변경은 HTML 요소 연결, 12줄 초기 내용, 기존 영역과 이벤트 보존, 저장 예외 처리 등을 정적으로 점검했습니다. 실제 브라우저에서 코드 편집, 저장, 새로고침 후 복원, 애니메이션, 모바일 화면을 실행 검증하지는 않았습니다.

1. `index.html`을 열고 코드 중간에 한글을 입력한 뒤 복사·붙여넣기, Enter, Backspace, Delete, Tab을 사용합니다. 줄 수와 번호, 스크롤 시 색상 위치를 확인합니다.
2. 하단 '이 브라우저에 저장됨'을 확인한 뒤 새로고침하고 브라우저를 닫았다가 같은 파일을 다시 열어 내용이 남는지 확인합니다.
3. 전체 선택 후 삭제하고 새로고침합니다. 예시 대신 빈 코드와 01번 줄이 표시되어야 합니다.
4. 여러 줄을 작성하고 스크롤한 뒤 X와 다시 열기를 눌러 내용·스크롤·좌측 홍보 문구 위치가 유지되는지 확인합니다.
5. 초기화 확인창에서 취소한 경우 내용이 유지되고, 확인한 경우 12줄 예시로 돌아오는지 확인합니다. 다시 새로고침해 초기화된 내용도 저장되었는지 확인합니다.
6. 개발자 도구 등으로 사이트 저장을 차단하고 다시 열어 저장 불가 안내와 편집·닫기·초기화·기존 메뉴의 정상 작동을 확인합니다.
7. 375px·768px·1440px 화면과 키보드 Tab 이동을 확인합니다. 교육과정 이동, 모바일 메뉴, 과정 상세 팝업도 확인합니다.
